# 🎬 Reproductor Flotante - Video Vivo

[![GitHub Pages](https://img.shields.io/badge/GitHub%20Pages-Live-brightgreen)](https://tu-usuario.github.io/reproductor-flotante)
[![PWA](https://img.shields.io/badge/PWA-Ready-blue)](https://tu-usuario.github.io/reproductor-flotante)
[![Mobile](https://img.shields.io/badge/Mobile-Friendly-green)](https://tu-usuario.github.io/reproductor-flotante)

Un reproductor de video flotante que se superpone sobre otras aplicaciones, optimizado para PC y dispositivos móviles Android.

## 🌟 Características

- ✅ **Flotante**: Se superpone sobre todas las aplicaciones
- ✅ **PWA**: Instalable como aplicación nativa
- ✅ **Multiplataforma**: Funciona en PC y Android
- ✅ **Responsive**: Adaptado para móviles y escritorio
- ✅ **Offline**: Funciona sin conexión a internet
- ✅ **Arrastrable**: Se puede mover libremente
- ✅ **Redimensionable**: Se puede cambiar el tamaño
- ✅ **Controles Personalizados**: Interfaz limpia y moderna

## 📱 Instalación en Dispositivos

### Android
1. Abre el enlace en Chrome
2. Toca el menú (⋮) → "Agregar a pantalla de inicio"
3. Confirma la instalación
4. ¡Listo! La app aparecerá en tu pantalla de inicio

### PC (Chrome/Edge)
1. Abre el enlace en Chrome o Edge
2. Busca el icono de instalación en la barra de direcciones
3. Haz clic en "Instalar"
4. ¡Listo! La app se instalará como aplicación de escritorio

## 🛠️ Uso

### Controles Básicos
- **Arrastrar**: Mueve el reproductor arrastrando el header
- **Redimensionar**: Cambia el tamaño desde las esquinas
- **Play/Pause**: Botón ▶ o barra espaciadora
- **Pantalla Completa**: Botón ⛶ o tecla F
- **Configuración**: Botón ⚙ para opciones avanzadas

### Teclas de Acceso Rápido
- `Espacio` - Play/Pause
- `F` - Pantalla completa
- `M` - Minimizar
- `S` - Configuración
- `Escape` - Salir de pantalla completa

### Modo Móvil
- **Touch**: Controles optimizados para pantalla táctil
- **Orientación**: Se adapta automáticamente
- **Gestos**: Soporte para gestos táctiles
- **PWA**: Instalable como app nativa

## 🔧 Configuración

### Cambiar el Video
1. Reemplaza el archivo `media/vivo.mp4`
2. O usa el panel de configuración para cargar una URL

### Personalizar
- **Tamaño**: Modifica las dimensiones en `styles.css`
- **Colores**: Cambia la paleta de colores
- **Controles**: Añade o modifica botones

## 🌐 Despliegue

### GitHub Pages (Automático)
1. Fork este repositorio
2. Ve a Settings → Pages
3. Selecciona "Deploy from a branch"
4. Elige "main" branch
5. ¡Listo! Se desplegará automáticamente

### Despliegue Manual
```bash
# Clonar repositorio
git clone https://github.com/tu-usuario/reproductor-flotante.git

# Navegar al directorio
cd reproductor-flotante

# Servir localmente
python -m http.server 8000
# O usar cualquier servidor web
```
